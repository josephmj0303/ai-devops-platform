# Authentication and RBAC

## Overview

The AI DevOps Platform protects DevOps operations through authentication
and role-based access control.

## Authentication

Users must authenticate before accessing protected platform functionality.

## Authorization

Role-based authorization controls access to DevOps operations exposed
through the backend API and frontend.

## Security Considerations

Authentication and authorization provide a security boundary between
general platform access and operational capabilities such as Kubernetes
inspection and DevOps actions.

This prevents unrestricted users from directly invoking operational
functionality.
